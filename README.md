# README en proceso

## Convención de ramas

```markdown
main              → rama principal, siempre estable
feature/<issue>   → nueva funcionalidad  (ej: feature/42-crud-socios)
fix/<issue>       → corrección de bug    (ej: fix/57-validacion-form)
```

Cada rama debe asociarse al número de issue correspondiente y mergearse a `main` mediante un Pull Request.
